# app_parsing_directory_and_csv
# Описание программного продукта

## Назначение
Программа предназначена для обработки TSV-файлов, содержащих биологические данные (связанные с опухолями).

## Структура программы
Программа состоит из двух основных модулей:
1. main.py - основной файл, отвечающий за запуск программы и взаимодействие с пользователем
2. parsing_catalogs.py - файл с функциональными компонентами для обработки данных

## Принцип работы
1. Запуск программы через main.py
2. Открытие диалогового окна для выбора папки с данными
3. Сканирование выбранной директории на наличие TSV-файлов
4. Извлечение данных из столбца tpm_unstranded
5. Сохранение результатов в файл result.json

## Основные компоненты

### Переменные:
- folder_path - хранит путь к выбранной папке
- passes - список путей к подходящим файлам
- data_dict - словарь с обработанными данными
- json_data - структурированные данные для сохранения
- root - основное окно приложения
- browse_button - кнопка выбора папки

### Функции:

#### 1. Выбор директории:
- browse_folder1() - простое открытие диалогового окна
- browse_folder() - расширенная версия с обработкой файлов

#### 2. Работа с файлами:
- show_folder_contents() - выводит содержимое выбранной папки
- pars() - сканирует файлы без строки "parcel" в названии
- reading_file() - читает TSV-файлы и извлекает данные

## Процесс обработки
1. Пользователь выбирает папку через графический интерфейс
2. Программа сканирует все файлы в директории
3. Исключаются файлы с "parcel" в названии
4. Из TSV-файлов извлекаются данные из столбца tpm_unstranded
5. Результаты преобразуются в числовой формат
6. Информация сохраняется в result.json

## Формат вывода
Файл result.json содержит:
```json
{
  "passes": [
    "путь к файлу 1",
    "путь к файлу 2"
  ],
  "data": {
    "путь к файлу": [числовые данные]
  }
}
```


## Порядок использования
1. Скачать main.py и parsing_catalogs.py
2. Поместить файлы в отдельную папку
3. Запустить main.py
4. В открывшемся окне выбрать папку с данными
5. Дождаться завершения обработки
6. Результаты будут сохранены в result.json
